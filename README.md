# Shubham Patel — Portfolio

A responsive, dark-themed personal portfolio website using the profile photograph supplied by Shubham.

## Preview locally
Open `index.html` in a browser. For a local server, run:
```bash
python -m http.server 8000
```
Then visit http://localhost:8000.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `shubham-portfolio`).
2. Upload all files and folders in this project. Keep the `assets/images/` folder structure unchanged.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.

All local asset references are relative (`assets/images/...`) so they work on GitHub Pages project sites as well as root sites.

## Personalize before publishing
- Replace `your-email@example.com` in `index.html` with an email address you want visitors to use.
- Replace the sample project cards with your real projects and links.
- Update the skills section as you gain experience.
- The page currently uses only the supplied photograph; it does not generate or alter your face.
